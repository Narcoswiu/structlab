# Прототип на дизайна (еталон за визията)

Тези файлове са **изходният код на прототипа** от Claude Design. Те са **референция**, не готов код за проекта:
форматът `.dc.html` (`<x-dc>`, `{{...}}`, `<sc-for>`, `<sc-if>`, `DCLogic`) работи само в Claude Design.
В проекта всичко се изгражда наново с Next.js + Tailwind + shadcn/ui, като се спазват:
- структурата и подредбата на секциите;
- цветовете, шрифтовете, отстоянията и заобленията (inline стиловете показват точните стойности);
- 3D ефектите (CSS класовете `.t3d`, `.lift`, `.float3d`, `.spin3d`, `.intro3d` в `<style>` на всеки файл);
- текстовете (на български).

| Файл | Екран |
|---|---|
| Main.dc.html | Начална страница (герой с 3D под, 3D греда „I“, възможности, метод, специалности, лично задание, AI, цени) |
| Welcome.dc.html | Въведение – обиколка в 7 стъпки |
| Library.dc.html | Табло на студента (продължи, повторение, път на модула, модули по курсове) |
| Reader.dc.html | Учебник – Глава 6 (теми светла/сепия/тъмна, размер на шрифта, Леко/Подробно, PDF) |
| BeamLab.dc.html | Лаборатория за греди (живи диаграми Q и M) |
| Admin.dc.html | Админ табло (показатели, потребители, времева линия, напомняния) |

`media/` съдържа фигурите, използвани в учебника. В прототипа те са заредени като `/_blob/...`.
Логиката в `<script type="text/x-dc">` (напр. изчисленията в BeamLab) е полезна референция за `lib/engineering`.
