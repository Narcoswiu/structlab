# StructLab

Онлайн учебна платформа по **Съпротивление на материалите** за студенти по строително инженерство:
учебници в два режима („Леко“ и „Подробно“), интерактивни лаборатории, лични задания по факултетен
номер, тестове с повторение и AI асистент по съдържанието.

> **Състояние:** в разработка. Готов е Етап 3 – основа и дизайн система (начална страница и
> компоненти). Вход, плащания, учебник и лаборатории идват в следващите етапи – виж
> [пътната карта](docs/ROADMAP.md).

## Технологии

| Област     | Избор                                                                    |
| ---------- | ------------------------------------------------------------------------ |
| Приложение | Next.js 16 (App Router), React 19, TypeScript (strict)                   |
| Стилове    | Tailwind CSS 4, shadcn/ui, Framer Motion, lucide-react                   |
| Тестове    | Vitest + Testing Library (unit), Playwright (браузър, телефон и десктоп) |
| Планирано  | Supabase (Postgres, Auth, Storage), Stripe, Resend, MDX + KaTeX          |

## Стартиране

Нужни са [Node.js](https://nodejs.org) 20+ и [pnpm](https://pnpm.io).

```bash
pnpm install
cp .env.example .env.local   # за този етап не са нужни ключове
pnpm dev
```

Сайтът се отваря на <http://localhost:3000>. Витрината на дизайн системата е на `/design`.

## Команди

| Команда                     | Какво прави                                                             |
| --------------------------- | ----------------------------------------------------------------------- |
| `pnpm dev`                  | локален сървър за разработка                                            |
| `pnpm build` / `pnpm start` | продукционна версия                                                     |
| `pnpm lint`                 | проверка на кода с ESLint                                               |
| `pnpm typecheck`            | проверка на типовете                                                    |
| `pnpm test`                 | unit тестове                                                            |
| `pnpm e2e`                  | тестове в браузър (първия път: `pnpm exec playwright install chromium`) |
| `pnpm format`               | форматиране с Prettier                                                  |

## Структура

```
app/                 маршрути (App Router)
  (marketing)/       публични страници: начало и временни страници „Скоро“
  design/            витрина на дизайн системата
components/
  ui/                базови компоненти (shadcn/ui)
  layout/            лого, хедър, футър
  home/              секциите на началната страница
  three-d/           3D ефекти само с CSS (мрежа-под, греда „I“, наклон на карти)
  PageIntro.tsx      каре „Какво е тази страница“
lib/                 помощни функции (формат на числа, настройки на сайта)
content/             учебно съдържание и речник на термините
docs/                спецификация, пътна карта, решения, прототип на дизайна
tests/               unit тестове
e2e/                 тестове в браузър
```

## Дизайн

- Цветовете са CSS променливи (`--sl-*` в [`app/globals.css`](app/globals.css)); компонентите не
  съдържат твърдо зададени цветове.
- Шрифтове с кирилица: Unbounded (заглавия), Manrope (интерфейс), Literata (четене),
  JetBrains Mono (числа). Сервират се от самия сайт.
- Всички анимации се изключват при `prefers-reduced-motion`.
- Числата са с десетична запетая и интервал преди мерната единица: `5,4 m`, `52 kN·m`.
- Всичко, което се натиска, е поне 44 px високо.
